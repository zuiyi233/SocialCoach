# 重练前后的原话对照

复盘页新增“前后对照”阅读入口和“两次练习的原话对照”区。用户完成同条件的独立重练后，先看两次引用的原话，再读各次已有复盘解释；点击引文打开对应完整对话，也可进入上次完整复盘。

## 比较边界

- 当前及历史记录都已复盘，使用 `scoringVersion: 2`；评级只接受本场真实 learner 转录中的连续引文。
- 比较场景 ID、角色、难度、限时模式、开场、回合范围、公开背景 / 目标、角色信息边界、固定事实 / 剧情方向，以及个性化简报 / 目标。记录条件不同则不出对照。
- 3D 还比较空间与开局，排除同一个 `practiceId` 的继续对话；缺失身份的旧 3D 档不猜测其独立性。每个历史 practice 使用最近的已复盘快照。
- 只选当前练习开始时间之前的记录，避免读旧报告时拿未来练习当“上次”。选最近的可比较记录，每次最多展示三个共同技能。
- 引文缺失、NPC 原话、无对应技能、重复评级、旧评分格式均不会成为比较依据。
- 相同 / 降低的模型评级仍展示；NPC 是否让步、目标是否成功不转成用户能力变化。两次动态对话的具体压力仍可能不同。

## 数据与交互

`lib/practice-comparison.ts` 只读取两份场次快照，派生对照行；不改写历史、不更新能力、不增加模型请求或遥测。`PracticeComparison` 使用现有双语、设计 token、完整对话阅读器与路由；复盘流式生成期间不显示比较。

缺少两份可核对记录时显示下一步说明，不填充零分、模拟原话或通用“进步”评价。已有的“再练一次”继续创建新场次，保持原报告与转录。

## 验收

核心检查覆盖真实双场引文、最近历史选择、评级持平 / 降低、身份 / 难度 / 简报 / 信息边界变化、3D 同局去重与不同开局、历史快照选择及无证据记录。网页检查覆盖文字 / 3D、原话回溯与上次复盘链接、刷新、中英、明暗和两种视口；使用虚构档案并拦截模型及统计请求。

本轮程序及浏览器结果和发布状态维护于 [验收记录](../../reviews/review-2026-10-12-practice-comparison.md)。真实用户能否看懂并主动重练，留作后续试玩；不把模拟档案的网页通过写成用户效果。
